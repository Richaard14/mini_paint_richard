# Mini Paint p5.js

Aplikasi menggambar sederhana seperti Paint menggunakan p5.js.

## Fitur
- Load image dari komputer
- Point
- Line
- Triangle
- Rectangle
- Ellipse
- Arc
- Quad
- Polygon
- Flat color
- Select object
- Move / Translate
- Rotate
- Scale
- Delete
- Clear
- Save PNG

## Menjalankan
Buka `index.html` di browser. Untuk hasil terbaik gunakan Live Server di VS Code.

## Deploy ke GitHub Pages
1. Buat repository GitHub, misalnya `mini-paint`.
2. Upload `index.html`, `style.css`, `sketch.js`, dan `README.md`.
3. Masuk ke Settings > Pages.
4. Pada Build and deployment pilih `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Save.
7. Setelah selesai, website dapat diakses melalui:
   `https://USERNAME.github.io/mini-paint/`

Jika dosen benar-benar meminta format `USERNAME.github.io`, buat repository bernama persis `USERNAME.github.io`, lalu taruh file aplikasi di root repository.
